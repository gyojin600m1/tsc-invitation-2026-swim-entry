# 第57回 東京スイミングセンター優秀選手招待水泳競技大会 エントリー確認（非公式）

2026年10月30日(金)〜11月3日(火・祝)／東京アクアティクスセンター（50m・10レーン）
※10月29日(木)は公式練習日

公開URL（予定）: https://gyojin600m1.github.io/tsc-invitation-2026-swim-entry/

`index.html` 1ファイルで動く。外部への通信は、閲覧カウンター（Abacus）と、同じ場所の `version.json`（新しい結果のお知らせ用）だけ。

## できること

- **選手** … 名前・ひらがな・チーム名・選手番号で検索。押すと出場種目（組・レーン・記録・順位・決勝進出）が開く。
- **チーム** … 387団体を選手番号順に。名簿は 🔵男子／🔴女子／性別がまだ分からない選手 に分けて出す。
- **日程** … 5日間・競技No.1〜184。予選の組数・開始時刻。押すとその種目の結果（順位順／組・レーン順）と決勝スタートリスト。
- **招待** … 招待選手19名（アジア大会代表15・JO最優秀/優秀4）と日ごとの出場予定。
- **情報** … 日ごとの時間、決勝への進み方、件数の照合。

## 2段階で作っている

**第1段階（大会前）**: 10/23公開の「選手番号一覧表」だけで作る。ここには **選手番号・氏名・団体名しか無い**
（性別・学年・種目・エントリータイムは無い）。種目別のエントリー一覧は 10/2〜10/4 にしか公開されておらず、
予選のスタートリストも公開されない。

**第2段階（大会中）**: 東京都水泳協会が種目ごとに出すPDFを取り込む（二次要項10項）。
- 結果 `NNN.pdf` … 予選の結果には**棄権した人も含め出場者全員**が組/水路つきで載るので、予選が終わるとその種目のエントリーが全部分かる。
- 決勝スタートリスト `SNNN.pdf` … 登録No.（＝選手番号）・ヨミガナつき。
- 取り込んだ種目の性別から、選手の性別を付ける（名前からの推測はしない）。

PDFの場所は、協会サイトの「競泳競技結果」記事に並ぶリンクを使う。記事がまだ無いときは昨年と同じ形
`https://tokyo-swim.org/result/2026/261030/{S}NNN.pdf` を試す（昨年は5日分とも初日のフォルダだった）。

## 速報の流れ

```
watch/update.py（Mac の launchd・毎分・10/30〜11/3 の 8:50〜19:00）
  └ tools/live_update.py  … 出ているはずのPDFだけ ETag つきで確認 → 変わったものだけ読む → data/live.json
       └ tools/build.py   … template.html に差し込んで index.html / version.json
  └ git commit & push → GitHub Actions（pages.yml）が Pages に公開
```

- レースの結果を見に行くのは「次の競技No.の開始時刻の2分前」から。取り込み済みは当日5分・前日まで30分おきに訂正だけ確認。
- 見出しの競技No.・性別・距離・種目が競技日程と違うPDFは取り込まない（前の内容を残す）。
- GitHub Actions の cron は数時間おきにしか動かないことがあったので使わない（日本選手権25mの教訓）。
  Mac が止まっているときは、スマホで Actions → pages → Run workflow を押すと取り込みから実行できる。
- 11/3 19:30 を過ぎると見張りは自分で止まる。手で一度回すときは `watch/いま確認する.command`。

## 作り直し

```bash
python3 tools/prepare.py      # 公式PDF → data/base.json（集計値と合わなければ止まる）
python3 tools/build_yomi.py   # KANJIDIC2 → data/yomi.json（検索用の読み。画面には出さない）
python3 tools/build.py        # → index.html / version.json
```

昨年（第56回）の初日PDFで試す: `python3 tools/live_update.py --now 2026-10-30T16:00 --base https://tokyo-swim.org/result/2025/251030/ --out /tmp/t.json`
→ `python3 tools/build.py --live /tmp/t.json --out test2025`
